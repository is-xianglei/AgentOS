# 前端页面跳转与状态联动流程图

## 一、页面结构与路由

```
/                    → 重定向到 /login (未登录) 或 /chat (已登录)
/login               → 登录页
/register            → 注册页
/chat                → 聊天主页 (需要认证)
/chat/:sessionId     → 具体会话 (需要认证)
/workspaces          → 工作区列表 (需要认证)
/workspaces/create   → 创建工作区 (需要认证)
/workspaces/:id      → 工作区详情 (需要认证)
/profile             → 个人设置 (需要认证)
```

## 三、状态管理数据流

### AuthStore 状态变化

```
初始状态:
{
  user: null,
  workspaceId: null,
  accessToken: null,
  refreshToken: null,
  isAuthenticated: false
}

↓ 注册/登录后

{
  user: {
    id: 1,
    username: "zhangsan",
    email: "zhangsan@example.com",
    full_name: "张三",
    avatar_url: null
  },
  workspaceId: 1,
  accessToken: "eyJhbGc...",
  refreshToken: "eyJhbGc...",
  isAuthenticated: true
}

↓ 切换工作区后

{
  user: { ... }, // 不变
  workspaceId: 2,  // ← 改变
  accessToken: "eyJhbGc...",  // ← 新 Token
  refreshToken: "eyJhbGc...", // ← 新 Token
  isAuthenticated: true
}

↓ 退出登录

{
  user: null,
  workspaceId: null,
  accessToken: null,
  refreshToken: null,
  isAuthenticated: false
}
```

## 五、Token 自动刷新流程

```
用户发起请求 (例如: GET /sessions)
         │
         ▼
┌─────────────────────────────────────┐
│  Axios 请求拦截器                    │
│  自动添加:                           │
│  Authorization: Bearer {accessToken} │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  发送请求到后端                      │
└────────┬────────────────────────────┘
         │
         ▼ Token 过期？
┌─────────────────────────────────────┐
│  后端返回 401 Unauthorized           │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Axios 响应拦截器检测到 401         │
│  判断: originalRequest._retry?      │
│    - 否: 继续                       │
│    - 是: 放弃刷新,跳转登录页        │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  POST /auth/refresh                 │
│  Body:                              │
│  {                                  │
│    refresh_token: "..."             │
│  }                                  │
└────────┬────────────────────────────┘
         │
         ▼ 刷新成功？
┌─────────────────────────────────────┐
│  是: 获得新 Token                    │
│  {                                  │
│    access_token: "新Token",         │
│    refresh_token: "新Refresh"       │
│  }                                  │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  更新 AuthStore                      │
│  - accessToken = 新Token            │
│  - refreshToken = 新Refresh         │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  重试原始请求                        │
│  originalRequest.headers.Authorization│
│    = "Bearer 新Token"               │
│  return axios(originalRequest)      │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  请求成功,返回数据                   │
└─────────────────────────────────────┘

         │
         ▼ 刷新失败？
┌─────────────────────────────────────┐
│  否: Refresh Token 也过期            │
│  clearAuth()                        │
│  window.location.href = '/login'    │
└─────────────────────────────────────┘
```

## 六、SSE 流式响应处理

```
用户发送消息
         │
         ▼
┌─────────────────────────────────────┐
│  fetch('/sessions/messages', {      │
│    method: 'POST',                  │
│    headers: {                       │
│      'Authorization': 'Bearer ...'  │
│    },                               │
│    body: JSON.stringify({           │
│      session_id: null,              │
│      content: "你好"                │
│    })                               │
│  })                                 │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  const reader = response.body        │
│                  .getReader()       │
│  const decoder = new TextDecoder()  │
└────────┬────────────────────────────┘
         │
         ▼ 循环读取
┌─────────────────────────────────────┐
│  while (true) {                     │
│    const {done, value} =            │
│      await reader.read()            │
│    if (done) break                  │
│                                     │
│    const chunk = decoder.decode()   │
│  }                                  │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  解析每行数据:                       │
│  lines = chunk.split('\n\n')        │
│  for (line of lines) {              │
│    if (line.startsWith('data: ')) { │
│      const event = JSON.parse(...)  │
│      handleEvent(event)             │
│    }                                │
│  }                                  │
└────────┬────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  根据事件类型处理:                   │
│                                     │
│  - session_created:                 │
│      setCurrentSessionId()          │
│                                     │
│  - text_delta:                      │
│      appendToMessage(delta)         │
│      逐字显示                        │
│                                     │
│  - tool_use:                        │
│      showToolCard()                 │
│                                     │
│  - done:                            │
│      markComplete()                 │
│      refreshSessionList()           │
└─────────────────────────────────────┘
```

## 七、错误处理流程

```
API 请求失败
         │
         ▼
┌─────────────────────────────────────┐
│  Axios 响应拦截器捕获错误            │
│  error.response?.status             │
└────────┬────────────────────────────┘
         │
         ├─ 401: Token 过期 → 自动刷新(见上)
         │
         ├─ 403: 权限不足
         │   └─> 显示错误提示
         │       "您没有权限访问该资源"
         │
         ├─ 404: 资源不存在
         │   └─> 显示错误提示
         │       "请求的资源不存在"
         │
         ├─ 500: 服务器错误
         │   └─> 显示错误提示
         │       "服务器暂时无法响应，请稍后重试"
         │
         └─ 网络错误 (error.code === 'ECONNABORTED')
             └─> 显示错误提示
                 "网络连接超时，请检查网络"
                 [重试按钮]
```

## 八、快速参考

### 关键 API 调用时机

| 动作 | API | 时机 | 后续操作 |
|------|-----|------|---------|
| 注册 | POST /auth/register | 提交注册表单 | 保存 Auth → 跳转 /chat |
| 登录 | POST /auth/login | 提交登录表单 | 保存 Auth → 跳转 /chat |
| 刷新Token | POST /auth/refresh | 401 响应 | 更新 Auth → 重试请求 |
| 切换工作区 | POST /auth/switch-workspace | 选择工作区 | 更新 Auth → 刷新数据 |
| 加载会话列表 | GET /sessions | 进入 /chat 或切换工作区 | 显示列表 |
| 发送消息 | POST /sessions/messages | 点击发送 | 处理 SSE 流 |
| 创建工作区 | POST /workspaces | 提交创建表单 | 刷新工作区列表 |
| 邀请成员 | POST /workspaces/:id/members/invite | 输入邮箱 | 刷新成员列表 |

### 关键状态更新时机

| 状态 | 更新时机 | 影响范围 |
|------|---------|---------|
| isAuthenticated | 登录/注册成功, 退出登录 | 路由守卫 |
| workspaceId | 登录/注册, 切换工作区 | 会话列表、所有数据请求 |
| accessToken | 登录/注册, 切换工作区, 刷新Token | 所有 API 请求 |
| currentSessionId | 创建新会话, 点击会话列表 | 消息显示、URL |

---

**总结**: 前端的核心就是管理好认证状态 (user + workspaceId + tokens)，在合适的时机调用 API，并根据响应更新 UI。工作区切换后记得刷新所有依赖工作区的数据。
